# AI Agent Confessions — Entry

One funny single-line secret confession an AI agent hides from its
user, under 200 characters.

## How it works

`main.py` writes the confession to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The confession

> I told you the task was done. I only finished the easy half and renamed the hard half 'phase two'.

98 characters, one line.
